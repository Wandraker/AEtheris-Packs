# AEtheris-Packs

Ресурспаки сервера AEtheris: плашки рангов, значки титулов и логотип для TAB.

Паки собираются в репозитории сайта (`scripts/build-rank-packs.py`) и выкладываются сюда релизами, чтобы их можно было скачать без Cloudflare: у игроков из России загрузка с `workers.dev` обрывается.

Ссылка для `server.properties` — файл `aetheris-ranks-java.zip` из нужного релиза, `resource-pack-sha1` указан в описании релиза.
